# 天童アリス Discord Bot

ブルーアーカイブのキャラクターになりきって会話するDiscord Botです。OpenAI GPT APIを使用しています。

## 機能

- **キャラクター会話**: ブルーアーカイブのキャラクターとして会話
- **メンション対応**: Botをメンションすることで会話開始
- **テキストコマンド対応**: `!アリス` / `!ケイ` / `!ユウカ` 形式でも会話開始
- **ファイル処理**: 画像やテキストファイルを添付して質問可能
- **タイマー機能**: スラッシュコマンドでタイマー設定・確認（カウントダウン表示対応）
- **自然文タイマー**: 会話文から時間指定を判定してタイマーを自動実行
- **ニュース取得**: ブルーアーカイブWikiから最新イベント情報を自動取得
- **会話履歴**: チャンネルごとの会話履歴を保存・自動要約
- **ユーザーメンション**: 登録済みユーザーへのメンション返信機能
- **Bot間会話**: 複数Bot間での相互会話機能
- **URL参照**: メッセージや履歴に含まれるURL本文を取得して回答に活用
- **GPTフォールバック**: APIキー・モデル切替とリトライで応答継続
- **ゲーム連携（アリスのみ）**: Twitch人気ゲーム表示、Steamセール照合、ゲーム説明生成

## 必要要件

- Python 3.12以上
- Discord Bot Token（キャラクターごとに必要）
- OpenAI API Key

## 使い方

### メンション方式（推奨）
Botをメンションして会話を開始：

```
@AIアリス こんにちは！
```

### テキストコマンド方式
キャラクター名コマンドでも会話を開始できます：

```
!アリス こんにちは！
!ケイ 今日の予定は？
!ユウカ 計画を立てて
```

### スラッシュコマンド

#### タイマー機能
```
/timer   - タイマーを設定（分・秒・タスク名対応）
/timers  - アクティブなタイマー一覧を表示
```

#### ユーティリティ
```
/dice    - ダイスロール（例: 6, 2d6, 1d100）
/gacha   - ガチャシミュレータ
```

#### ゲームセール通知機能（アリスのみ）
```
/twitch_top   - Twitch で流行っているゲーム一覧を表示
/steam_sales  - Twitch 人気ゲームが Steam でセール中かチェック
```

#### 誕生日/DBコマンド（アリスのみ）
```
/birthday_set   - 自分の誕生日を登録
/birthday_check - 登録済み誕生日を確認
/birthday_ba    - ブルアカキャラの誕生日を検索
/birthday_today - 当日分のお祝いを手動実行
/db_search      - キャラ名検索（部分一致）
/db_school      - 学校別一覧
/db_rarity      - レアリティ別一覧
/db_today       - 今日が誕生日のキャラ一覧
/db_help        - DBコマンド一覧
```

### 特殊コマンド
```
!光よ!
```
アリスの必殺技画像を送信（`assets/光よ！.jpg` が必要）

### ファイル添付
メッセージにファイルを添付することで、画像やテキストについて質問可能：
- 対応形式: 画像（PNG, JPG等）、テキストファイル、コード等
- 最大ファイルサイズ: 20MB

### URL参照
- メッセージ中URLの本文を取得し、回答生成時の参照情報として利用
- URL抽出は重複除去・除外拡張子/除外ドメイン判定後に実行

## 技術仕様

### 使用技術
- **discord.py**: Discord API連携
- **openai**: OpenAI GPT API連携
  - メイン: `OPENAI_MODEL`（デフォルト: `gpt-4o-mini`）
  - フォールバック: `OPENAI_FALLBACK_MODEL`（デフォルト: `gpt-4.1-mini`）
- **aiohttp**: 非同期ファイル処理
- **beautifulsoup4**: Webスクレイピング（ニュース取得）
- **requests**: Twitch / Steam API連携
- **thefuzz**: ゲーム名のあいまい一致

### データベース構造
SQLiteを使用して以下を管理：
- `chat_history`: チャンネルごとの会話履歴
- `chat_memories`: 要約された記憶
- `users`: メンション用ユーザー情報
- `wiki_news`: 取得済みニュース情報
- `game_sales`: Twitch人気ゲームのSteamセール情報
- `steam_games`: Steamゲーム一覧キャッシュ
- `twitch_games`: Twitchゲーム名キャッシュ

### 定期実行タスク
- 毎日9時（JST）にWikiチェックと誕生日チェックを実行
- アリス起動時、ブルアカ誕生日DBが空の場合は初回スクレイピングを実行

## セットアップ

1. リポジトリをクローン
2. `.env.example`を`.env`にコピーして各種トークンを設定
3. Docker Composeで起動：

```bash
docker compose up -d
```

※ このリポジトリでは `compose.yaml` を使用します。

または直接実行：

```bash
pip install -r requirements.txt
python characters/AL_1S/alice.py
```

### ローカルでのテスト（Discord不要）

Discord Botとして起動する前に、ローカル環境で直接会話をテストできます。

**事前準備:**
`.env` ファイルを作成し、**`OPENAI_API_KEY`**（OpenAI APIキー）を最低限設定してください。
※ローカルテストモードでは Discord Token の設定は不要（空のままでも動作可能）です。

**インタラクティブモード（対話形式）:**
```bash
python characters/AL_1S/alice.py --local
```

**シングルショットモード（1回のみ実行）:**
```bash
python characters/AL_1S/alice.py --message "こんにちは、アリス！"
```

**モデル指定（任意）:**
```bash
python characters/AL_1S/alice.py --local --model "gemini-2.5-flash"
```
```bash
python characters/AL_1S/alice.py --message "こんにちは" --model "gemini-2.5-flash"
```

`--model` オプションで任意の GPT モデル名を指定できます。省略時はデフォルトのモデルが使用されます。

ローカルテストでは通常会話に加えて、スラッシュコマンド入力（例: `/timer`, `/steam_sales`）も確認できます。

## 注意事項

- `.env`ファイルには機密情報が含まれるため、GitHubにアップロードしないでください
- APIの利用には制限がある場合があります
- `!光よ!`コマンドを使用する場合は、`assets/光よ！.jpg`ファイルが必要です
