# 🎮 天童アリス Discord Bot

ブルーアーカイブ「天童アリス」のDiscord Botです。Google Gemini 3 Flash APIを使用して、アリスのキャラクターになりきって会話します。

## ✨ 機能

- **キャラクター会話**: ブルーアーカイブの天童アリスとして会話
- **メンション対応**: Botをメンションすることで会話開始
- **ファイル処理**: 画像やテキストファイルを添付して質問可能
- **動的推論レベル**: 質問の複雑さに応じて推論レベルを自動調整
- **長文対応**: 長い応答は自動的に分割またはファイルとして送信
- **特殊コマンド**: `!光よ!` コマンドで専用画像を送信

## 📋 必要要件

- Python 3.8以上
- Discord Bot Token
- Google Gemini API Key (Gen AI)

## 💬 使い方

### メンション方式（推奨）
Botをメンションして会話を開始します：

```
@天童アリス こんにちは！
```

### コマンド方式（後方互換性）
```
!アリス おはようございます
```

### 特殊コマンド
```
!光よ!
```
→ アリスの必殺技画像を送信（`assets/光よ！.jpg` が必要）

### ファイル添付
メッセージにファイルを添付することで、画像やテキストについて質問できます：
- 対応形式: 画像（PNG, JPG等）、テキストファイル、コード等
- 最大ファイルサイズ: 20MB

## 🔧 技術仕様

### 推論レベルの自動判定
Botは質問の複雑さに応じて3つの推論レベルを自動選択します：

- **Low**: 簡単な挨拶（例: 「こんにちは」）
- **Medium**: 通常の会話
- **High**: 複雑な質問、コード、説明を求める質問

### 使用技術
- **discord.py**: Discord APIとの連携
- **google-genai**: Google Gemini 2.0 Flash連携
- **aiohttp**: 非同期ファイル処理

## 📝 ライセンス

個人使用・学習目的で作成されたプロジェクトです。

## ⚠️ 注意事項

- `.env` ファイルには機密情報が含まれるため、**絶対にGitHubにアップロードしないでください**
- APIの利用には制限がある場合があります。過度な使用にご注意ください
- `!光よ!` コマンドを使用する場合は、`assets/光よ！.jpg` ファイルが必要です

## 🎨 キャラクター設定

### 天童アリス
「ブルーアーカイブ」に登場するキャラクターで、以下の特徴があります：
- 夢は勇者になること
- 武器は光の剣「スーパーノヴァ」
- ミレニアムサイエンススクールのゲーム開発部に所属
- 一人称は「アリス」、二人称は「先生」

### ケイ（Key）
「ブルーアーカイブ」に登場するキャラクターで、以下の特徴があります：
- 元は天童アリスに内包されていたトリガーAI、現在はミレニアムサイエンススクール・ゲーム開発部の一員
- アリスへの使命感が強く、彼女を守ることが最優先
- ツンデレ（デレ多め）な性格で、「ケイちゃん」と呼ばれるのは恥ずかしがる
- タブレットを常備し、ゲーム好き
- 一人称は「私」、二人称は「先生」
- 白い髪、赤い瞳、赤いヘイロー

詳細な設定は各キャラクターの `SYSTEM_INSTRUCTION` に記載されています。
